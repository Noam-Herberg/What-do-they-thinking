# Campaign Lab Crab Rave

A tiny static site for GitHub Pages.

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, and `campaignlab_crab_rave.gif`.
3. In GitHub, open **Settings > Pages**.
4. Set **Source** to **Deploy from a branch**.
5. Choose the `main` branch and `/root`, then save.

GitHub will publish the page at the URL shown in the Pages settings.
